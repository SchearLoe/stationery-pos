# 文具店收银系统（Stationery POS）

为小型文具/文体用品店打造的收银与进销存系统。云端单一数据源，Windows 桌面收银端，后续扩展鸿蒙 / iOS 移动端。

> 规划文档见仓库外《文具店收银系统-整体规划.md》（一期范围：收银、商品、库存、交接班、简版报表、权限）。

## 功能（一期）

| 模块 | 说明 |
|---|---|
| POS 收银 | 扫码枪收银、组合支付（现金/微信/支付宝/刷卡）、现金找零、整单优惠、挂单/取单、收银全程可纯键盘操作（F1 挂单 / F4 优惠 / F9 结算） |
| 离线收银 | 断网可正常扫码开单收款（本地缓存价），单据存本机 outbox 队列，恢复网络后按下单顺序自动上云；顶栏实时显示同步状态，失败单可人工重试 |
| 商品管理 | SPU + 多规格 SKU、多条码、无码商品自动生成店内码、最低售价保护、停售/上架、CSV 批量期初导入 |
| 库存管理 | 实时库存与流水（销售/退货/调整/期初全链路可追溯）、低库存预警、老板库存调整（盘点差异/报损） |
| 退货 | 按原单部分/全部退货，自动回补库存、可退数量控制、原因必填 |
| 交接班 | 开班/关班、各支付方式净额统计、实点现金差异、班次历史 |
| 销售记录 | 订单查询/详情、整单作废（老板，红冲回补库存） |
| 经营分析 | 净销售额/订单/客单价/库存资金 KPI、每日销售趋势、支付方式分布、商品销量排行 |
| 小票打印（可选） | 默认关闭、不影响收款；两种方式按需开启：① Windows 驱动打印（HTML 模板，可静默自动打印）② ESC/POS 直连（指令直送打印机字库，走 winspool RAW，免装驱动排版） |
| 权限 | 老板/收银员两级；收银员不可见进价成本（服务端字段级剔除）；改价低于最低售价、超限折扣需老板密码授权；敏感操作审计日志 |

## 功能（二期）

| 模块 | 说明 |
|---|---|
| 采购/应付 | 供应商档案、采购单（待入库 → 入库/取消）；入库自动加库存并更新最近进价与移动加权平均成本；按单登记付款（支持分次），按供应商汇总应付余额 |
| 盘点任务 | 按类目或全店建任务（快照账面库存）→ 逐项录入实盘数（可分批保存）→ 应用差异自动生成 `STOCKTAKE` 库存调整流水；未盘项不动 |
| 会员储值/积分 | 会员档案（会员码 M 开头可扫码挂单）、充值+赠送、储值余额支付（组合支付）、积分按消费自动赠送、积分抵扣、会员价；退货/作废自动回补余额与积分；余额/积分全链路流水 |
| 账目与月结 | 杂项支出记账（房租/水电/工资/运费等）、月结报表：净销售、销售成本（下单时点成本快照）、毛利、采购入库与付款、支出分类、会员充值、净利估算 |
| 报表导出 | 经营分析页一键导出 CSV（Excel 直接打开）：销售汇总 / 每日销售 / 销量排行 / 销售明细 / 库存快照 / 月结报表 |
| 聚合支付对接 | **预留**：需微信/支付宝商户号与支付网关账号后开发（B 扫 C 收款码 + 异步回调入账），当前微信/支付宝按人工确认收款使用 |

## 技术栈

- **桌面端** `apps/desktop`：Electron + Vue 3 + TypeScript + Element Plus + Pinia
- **服务端** `apps/server`：NestJS 11 + Prisma + PostgreSQL，JWT 认证 + 角色守卫，事务化库存记账
- **共享类型** `packages/shared-types`：接口 DTO 与枚举（金额一律为「分」的整数）

> 备注：规划中桌面端首选 Tauri 2，因开发机无 Rust 工具链，一期落地采用备选方案 Electron（前端代码不依赖壳，后续可评估迁移 Tauri）。

## 快速开始（开发）

依赖：Node ≥ 20、pnpm ≥ 9、Docker（或任意 PostgreSQL 15+）

```bash
# 1. 安装依赖
pnpm install

# 2. 启动数据库
docker compose up -d

# 3. 初始化服务端
cd apps/server
cp .env.example .env
pnpm db:migrate      # 建表
pnpm db:seed         # 种子数据（默认账号 + 文体类目 + 演示商品）
pnpm start:dev       # API 运行在 http://localhost:3000

# 4. 启动桌面端（另开终端）
cd apps/desktop
pnpm dev             # Electron 窗口，连接本地 API
```

默认账号（seed 生成，**生产环境务必修改密码**）：

| 角色 | 用户名 | 密码 |
|---|---|---|
| 老板 | `boss` | `boss123` |
| 收银员 | `cashier` | `cashier123` |

## 硬件

- **扫码枪**：任意 USB HID 键盘口扫码枪即插即用（一维红光/激光即可），收银台保持光标在扫码输入框即可
- **小票打印机（可选）**：不接打印机也可正常收款。需要打印时在「系统设置 → 打印设置」开启：
  - *驱动打印*：安装厂商 Windows 驱动后即可，支持收款后自动静默打印
  - *ESC/POS 直连*：选择本机打印机名即可，指令直送打印机字库（中文按 GBK 输出），出票更快
- 后续硬件：钱箱（经打印机 RJ11 触发）、条码标签打印机

## 离线收银说明

- 收银端启动后自动缓存全量在售商品（IndexedDB，5 分钟刷新），断网时扫码/查价走本地缓存
- 断网收款：本地生成 `L` 前缀离线单号（小票标注「离线单·待同步」），单据进入本机 outbox 队列
- 恢复网络后按下单顺序自动补传（30 秒轮询 + 网络恢复事件触发），服务端按 `clientId` 幂等去重，离线单号唯一约束兜底，不会丢单也不会重复入账
- 离线单金额按「下单时点」价格入账；离线期间无法退货、无法开班/关班（需联网）
- 顶栏「同步状态」可查看队列、手动补传、处理失败单（如商品被删除导致的校验失败）
